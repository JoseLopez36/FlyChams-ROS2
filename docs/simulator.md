# Simulator

FlyChams-Sim-UE5 is the Unreal Engine 5 + AirSim environment used for software-in-the-loop (SITL) simulation.

## Prerequisites

- FlyChams-Sim-UE5 binary package.
- Generated AirSim settings: `config/generated/airsim.json` (run `scripts/launch_settings.sh` to generate).

## Launch

### Using the launch script (recommended)

```bash
scripts/launch_ue5_sim.sh /path/to/FlyChams-Sim-UE5
```

The script validates that the AirSim settings exist and launches the simulator with the correct settings path.

### Manual launch

```bash
/path/to/FlyChams-Sim-UE5/FlyChamsSim.sh -settings="path/to/FlyChams-ROS2/src/flychams_common/config/generated/airsim.json"
```

**Notes:**
- The `-settings` argument must be an absolute path.
- Launch the simulator **before** starting the FlyChams ROS2 stack (see [setup.md](setup.md)).

## Settings File

The AirSim settings JSON is generated by `scripts/launch_settings.sh` from:
- `src/flychams_common/config/core/system.yaml` — paths and simulation parameters
- Agent definitions in the configuration spreadsheet

Regenerate whenever the mission configuration changes:

```bash
scripts/launch_settings.sh
```
