# Foxglove Operator Interface

The `flychams_operator` package publishes metrics and visualization markers over a WebSocket via `foxglove_bridge`. [Foxglove Studio](https://foxglove.dev/studio) connects to it for real-time monitoring.

---

## Connection

1. Launch the operator: `scripts/launch_operator.sh`
2. Open Foxglove Studio → **Open connection** → **Foxglove WebSocket** → `ws://<host-ip>:8765`.
3. Import the layout: **File → Import layout from file** → `src/flychams_common/config/generated/flychams.json`.

> The layout is mission-specific and regenerated by `scripts/launch_settings.sh`. Re-import after changing the agent configuration.

### Button Extension (required for control panels)

Install the [Button extension](https://github.com/adityakamath/foxglove_extensions/releases) (`.foxe` file) via **Extensions → Install Extension**, then restart Foxglove.

---

## Layout

The auto-generated layout contains:

| Panel | Content |
|---|---|
| **3D Scene** | Situational awareness — agents, targets, clusters, markers |
| **Simulation Feeds** | One tab per agent with scenario camera views |
| **Camera Feeds** | Per-agent tabs: central + tracking unit images with detection annotations |
| **Agent Metrics** | Speed, altitude, distance-to-goal, optimization duration (time-synced) |
| **Mission Metrics** | Element counts, mission time, agent state timeline |
| **System Log** | ROS console (WARN+) |

### Control Area

Six toggle buttons publishing `std_msgs/Bool`:

| Button | Topic |
|---|---|
| Start | `/flychams/operator/start_mission` |
| Pause | `/flychams/operator/pause_mission` |
| Abort | `/flychams/operator/abort_mission` |
| Arm All | `/flychams/operator/arm_all` |
| Land All | `/flychams/operator/land_all` |
| Home All | `/flychams/operator/return_home` |

## Recording & Replay

All `/flychams/**` and `/rosout` topics are captured in MCAP format.

```bash
scripts/flychams.py sim --record           # record during simulation
RECORD=true scripts/launch_operator.sh     # record via operator only
```

Bags are saved to `recordings/`. To replay, open the `.mcap` file in Foxglove Studio (**Open local file**) and import the layout.

> Recordings are gitignored. Store long-term recordings outside the project root.
